# 🤖 AI Agent Development Track: Структура модулей

## 📚 Полный список модулей

### Уровень 1: Основы AI-разработки

#### Модуль 1: Введение в AI-агентов для разработки (2 недели)
**Статус:** ✅ Готово  
[Перейти к модулю](./Module_01_Introduction/content.md)

- Обзор инструментов (Copilot, Cursor, Claude)
- Настройка окружения и `.cursorrules`
- Основы промпт-инжиниринга

---

#### Модуль 2: AI-помощник в разработке UI (2 недели)
**Статус:** 📝 В разработке

- Генерация Compose компонентов с контекстом проекта
- Стилизация и темизация (Material 3, кастомные темы)
- Создание дизайн-системы из Figma макетов через ИИ

---

#### Модуль 3: AI в архитектуре и бизнес-логике (2 недели)
**Статус:** 📝 В разработке

- Проектирование архитектуры (DDD, Clean Architecture) с ИИ
- Dependency Injection: генерация Koin модулей
- Работа с данными: SQLDelight, Ktor Client из описания

---

#### Модуль 4: AI для тестирования и качества кода (2 недели)
**Статус:** 📝 В разработке

- Генерация unit-тестов (JUnit 5, Kotest) с edge cases
- UI-тестирование: Compose Test сценарии
- AI code review: поиск уязвимостей и code smells

---

### Уровень 2: Продвинутые техники

#### Модуль 5: AI в нативных интеграциях (2 недели)
**Статус:** 📝 В разработке

- Expect/Actual паттерн: генерация платформенных реализаций
- Работа с нативными API (iOS Swift, Android JNI)
- C-interop и Objective-C++ с помощью ИИ

---

#### Модуль 6: AI в DevOps и CI/CD (2 недели)
**Статус:** 📝 В разработке

- Генерация GitHub Actions workflows для KMP
- Feature flags и A/B тестирование с ИИ
- Мониторинг: Sentry, Crashlytics конфигурация

---

#### Модуль 7: Продвинутые техники и best practices (2 недели)
**Статус:** 📝 В разработке

- Custom AI Agents для специфичных задач
- AI в документации: KDoc, README, onboarding guides
- Безопасность и этика: риски, лицензирование, GDPR
- Anti-patterns: когда НЕ использовать ИИ

---

### Уровень 3: Мультиагентные системы и локальные модели

#### Модуль 8: Мультиагентность и оркестрация (3 недели)
**Статус:** ✅ Готово  
[Перейти к модулю](./Module_08_MultiAgent/content.md)

- Основы multi-agent systems и паттерны взаимодействия
- Фреймворки: LangChain, AutoGen, CrewAI
- Создание специализированных агентов (Code Review, Test Generator, Security Auditor)
- Интеграция с CI/CD пайплайнами

---

#### Модуль 9: Локальные LLM модели (3 недели)
**Статус:** ✅ Готово  
[Перейти к модулю](./Module_09_Local_LLM/content.md)

- Обзор моделей: Llama 3, Mistral, Phi-3, Qwen
- Запуск через Ollama, LM Studio, llama.cpp
- Интеграция в KMP через expect/actual (Android/iOS/Desktop)
- Оптимизация: квантование, GPU acceleration, context management
- Конфиденциальность и гибридный подход (локальная + cloud)
