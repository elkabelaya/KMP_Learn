# 🎨 Design System: EcoTrack

## 1. Цветовая палитра (Color Palette)
Используем природную, спокойную гамму.

| Название | HEX-код | Использование |
|----------|---------|--------------|
| **Primary Green** | `#4CAF50` | Кнопки, активные элементы, иконки достижений |
| **Secondary Green** | `#81C784` | Второстепенные элементы, прогресс-бары |
| **Dark Green** | `#2E7D32` | Акценты, заголовки в темной теме |
| **Background Light** | `#F5F7FA` | Основной фон (светлая тема) |
| **Background Dark** | `#121212` | Основной фон (темная тема) |
| **Surface** | `#FFFFFF` / `#1E1E1E` | Карточки, листы (Light/Dark) |
| **Text Primary** | `#212121` / `#FFFFFF` | Основной текст (Light/Dark) |
| **Text Secondary** | `#757575` / `#B0BEC5` | Второстепенный текст, подписи |
| **Error** | `#F44336` | Ошибки, удаление |
| **Success** | `#00E676` | Успешные действия, бейджи |

---

## 2. Типографика (Typography)
Шрифт: **Inter** или **Roboto** (стандартные для Android/iOS).

| Стиль | Размер | Вес | Использование |
|-------|--------|-----|--------------|
| **Display** | 32sp | Bold | Заголовки экранов (например, "Главная") |
| **Headline** | 24sp | SemiBold | Заголовки карточек, списков |
| **Title** | 18sp | Medium | Заголовки секций, кнопки |
| **Body** | 16sp | Regular | Основной текст, описания |
| **Caption** | 12sp | Regular | Подписи, даты, метаданные |

---

## 3. Компоненты (Components)

### 📱 Карточка привычки (Habit Card)
- **Фон:** Белый (Light) / Темно-серый (Dark)
- **Скругление:** 16px
- **Тень:** `elevation: 2dp` (для Android) / `shadow: 0 4px 12px rgba(0,0,0,0.1)` (для iOS)
- **Структура:**
  - Иконка (слева, 48x48px)
  - Название (Headline, слева от иконки)
  - Статус (справа: галочка или круг прогресса)
  - Дата (Caption, снизу справа)

### 🔘 Кнопка (Button)
- **Primary:** Фон `#4CAF50`, текст белый. Скругление 12px. Высота 48px
- **Secondary:** Прозрачный фон, обводка `#4CAF50`, текст зеленый
- **Floating Action Button (FAB):** Круглый, 56x56px, иконка `+`, цвет Primary

### 📊 График (Chart)
- **Тип:** Линейный график (Line Chart)
- **Линия:** `#4CAF50`, толщина 3px
- **Точки:** Круги, цвет Primary
- **Ось Y:** Сетка пунктирная, серый цвет

## 5. Инструкция по сборке в Figma (Step-by-Step)

1. **Создайте файл:** Откройте Figma -> New File
2. **Фрейм:** Создайте фрейм `iPhone 15` (390x844px) или `Android Phone`
3. **Сетка:** Включите Grid (Layout Grid) — 16px, чтобы соблюдать отступы
4. **Компоненты:** Создайте компоненты для Кнопки, Карточки и Нижней навигации (Bottom Navigation Bar)
5. **Сборка:** Соберите 4 экрана согласно схемам выше

### 📥 Полезные ресурсы (готовые UI-киты)
Чтобы не рисовать иконки с нуля, используйте бесплатные библиотеки в Figma Community:
- **Material Design 3** (официальный UI-кит от Google)
- **iOS 17 Design System** (официальный UI-кит от Apple)
- **Phosphor Icons** или **Heroicons** (для иконок привычек)

## 6. Как это использовать в коде?
Когда вы соберете макет, вам нужно будет:

1. **Извлечь цвета:** Скопируйте HEX-коды из Figma и создайте файл `Colors.kt` в `commonMain`
2. **Извлечь размеры:** Запишите отступы (16dp, 24dp) и создайте файл `Dimensions.kt`
3. **Извлечь шрифты:** Укажите размеры текста в `Typography.kt`

Это позволит вам легко перенести дизайн из Figma в Compose Multiplatform.

## 7. Prompt для Figma Make (AI)
Если вы хотите сгенерировать дизайн через AI в Figma, используйте этот промпт:

```
Создай UI-дизайн мобильного приложения «EcoTrack» — трекер экологических привычек. Стиль: чистый, современный минимализм с природной тематикой.

Цветовая палитра:
- Основной: Зеленый (#4CAF50) для кнопок, акцентов и активных элементов
- Фон: Светлый (#F5F7FA) для светлой темы, Темный (#121212) для темной
- Текст: Темно-серый (#212121) или Белый в зависимости от темы
- Карточки: Белые с мягкими тенями и скруглением 16px

Типографика: Sans-serif (Inter или Roboto). Заголовки Bold, основной текст Regular.

Структура экранов:
1. Главная (Home): Верхняя панель с приветствием и датой. Карточка с линейным графиком активности за неделю (Vico style). Ряд из 3 иконок достижений. Список карточек привычек (иконка, название, статус галочкой). Нижняя навигация: Главная, Статистика, Настройки. Плавающая кнопка (FAB) с плюсом для добавления.

2. Добавление привычки (Add Habit): Заголовок «Добавить». Поля ввода: Название, Категория (Dropdown с иконками), Дата (Picker), Комментарий. Кнопка «Сохранить» на всю ширину.

3. Статистика (Statistics): Большой линейный график активности за месяц. Секция достижений: карточки с иконками, статусом (разблокировано/заблокировано) и прогресс-баром.

4. Настройки (Settings): Карточка профиля с аватаром и именем. Переключатели (Switch) для «Уведомлений» и «Темной темы». Статус синхронизации. Кнопка выхода внизу.

Требования:
- Адаптивный дизайн под мобильные устройства (iOS/Android)
- Четкая иерархия контента
- Использование Material Design 3 компонентов (кнопки, инпуты)
- Иконки: линейные или плоские (flat), тематика экологии
```
